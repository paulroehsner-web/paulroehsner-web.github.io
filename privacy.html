Privacy Policy

Last updated: October 23, 2026

Paul-fitness-sync is a personal tool used only by its owner, Paul Roehsner. It is not available to other users.

What data is accessed

With the owner's explicit consent through Google sign-in, the app reads the owner's own Google Health data with read-only permissions: activity and fitness data, health metrics and measurements, and sleep data.

How data is used

The data is copied into the owner's private database solely so the owner can track his own fitness over time. It is not used for advertising, profiling, or any other purpose.

Sharing

The data is never sold, shared with, or transferred to any third party. The app never writes or changes any data in Google Health.

Storage and retention

Data and access tokens are stored privately with restricted file permissions. The owner can delete the data at any time and can revoke the app's access at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
